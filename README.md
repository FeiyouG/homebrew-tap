# FeiyouG Tap

## How do I install these formulae?

`brew install feiyoug/tap/<formula>`

Or `brew tap feiyoug/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "feiyoug/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
